# 🏆 World Cup 2026 Live Stream App

A fully functional IPTV and Live Sports streaming application built with **Flutter** and **Firebase Realtime Database**. 

## ✨ Features
- **Live Streaming (HLS/M3U8):** Smooth video playback for live sports and free TV channels using custom video player (`better_player` / ExoPlayer).
- **Dynamic Home Screen:** Beautiful UI with circular "Channel" styled categories and a featured video top banner.
- **Admin Panel:** Real-time dashboard to add, edit, or delete videos, live matches, and create new categories dynamically.
- **Firebase Integration:** Powered by Firebase Realtime Database for instant content updates without needing app updates.
- **Push Notifications:** Built-in global notification system with read-status red dot indicators.
- **HTTP/Cleartext Support:** Configured to handle standard free IPTV links (`http://`) seamlessly bypassing Android network security policies.
- **Live Menu UI:** Interactive IndexedStack navigation for instant zero-load switching between Home and Live screens.

## 🛠️ Tech Stack
- **Frontend:** Flutter (Dart)
- **Backend:** Firebase Realtime Database, Firebase Authentication
- **Video Player:** BetterPlayer (HLS support)
